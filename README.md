## 📌 Sobre o projeto

**Foi Sem Querer Querendo** é um projeto individual desenvolvido como parte da minha graduação na **SPTech**, inspirado no universo do seriado mexicano *Chaves*.

A proposta é criar uma plataforma interativa que reúna informações sobre o seriado, sua história e seus personagens, proporcionando aos usuários uma experiência que vai além de simplesmente conhecer a obra.

A ideia é transformar esse espaço em um ambiente onde seja possível explorar conteúdos, testar conhecimentos por meio de quizzes, conhecer episódios e interagir com diferentes funcionalidades da plataforma.

Mais do que um projeto acadêmico, esta também é uma oportunidade de trabalhar com um tema que possui um significado especial para mim.

## 💛 De onde veio a inspiração?

O universo de Chaves fez parte da história de muitas pessoas e continua presente na memória de diferentes gerações.

A escolha desse tema não aconteceu por acaso. Existe uma relação pessoal e afetiva com o seriado que me motivou a transformar esse interesse em um projeto de desenvolvimento web.

Por isso, a plataforma também contará com uma seção chamada **Motivação**, na qual compartilho um pouco dessa história, explicando o que me inspirou e por que escolhi esse universo para desenvolver meu projeto.

Afinal, algumas coisas fazem parte da nossa história de uma maneira especial e merecem ser lembradas.

## 🎯 Objetivos do projeto

O desenvolvimento do Foi Sem Querer Querendo possui dois objetivos principais:

- **Desenvolvimento técnico:** colocar em prática e aprofundar meus conhecimentos em desenvolvimento web, trabalhando com estruturação de páginas, estilização, interatividade e funcionalidades.
- **Desenvolvimento pessoal:** transformar uma inspiração pessoal em uma aplicação real, explorando a criatividade e construindo algo que tenha significado para mim.

## ✨ Funcionalidades

| Área | Descrição |

## 🛠️ Tecnologias utilizadas

As tecnologias utilizadas como base para o desenvolvimento da plataforma são:

- **HTML5:** responsável pela estruturação das páginas e organização dos elementos.
- **CSS3:** utilizado para a identidade visual, estilização, responsividade e apresentação dos componentes.
- **JavaScript:** responsável por adicionar interatividade e implementar as funcionalidades da plataforma.

## 🚀 Como executar o projeto

Para testar o **Foi Sem Querer Querendo** na sua máquina, siga os passos abaixo:

**1. Clone o repositório**

No GitHub, copie o link do repositório e execute o comando no terminal:

```bash
git clone LINK_DO_REPOSITORIO
```

**2. Abra a pasta do projeto**

Após clonar o repositório, acesse a pasta que foi criada no seu computador.

**3. Abra o CMD**

Dentro da pasta do projeto, clique na barra de endereço do Explorador de Arquivos, digite `cmd` e pressione Enter.

**4. Inicie a aplicação**

Com o CMD aberto na pasta do projeto, execute:

```bash
npm start
```

**5. Acesse a plataforma**

Após iniciar a aplicação, o terminal apresentará um endereço local, geralmente com o formato `http://localhost:PORTA`.

Pressione `Ctrl` e clique no link apresentado para abrir a plataforma no navegador.

Pronto! Agora você poderá explorar e testar o Foi Sem Querer Querendo.

*Observação: é necessário ter o Node.js instalado e as dependências do projeto configuradas. Caso seja necessário, execute `npm install` antes de iniciar a aplicação.*
